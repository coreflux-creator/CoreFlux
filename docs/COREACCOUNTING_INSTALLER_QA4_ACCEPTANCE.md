Later source commit `1076fa00` coordinates the canonical invoice emitter, posting rule, historical replay and legacy idempotency guard. Its fresh-database [CI run 37889700142](https://github.com/coreflux-creator/CoreFlux/actions/runs/37889700142) passed all eight jobs. ## Remaining gates

The default hostname now resolves; [Cloudways support request 987550](https://tickets.cloudways.com/hc/en-us/requests/987550) records the provider repair. The rebuilt package and corrected bank-account picker have passed the hosted recheck. Bank setup has not covered a second legal entity or the Plaid-created account path; current schema permits one bank account per tenant-level GL code, so multi-entity reuse of a standard code and Plaid's shared-GL default need a design and migration decision. This QA test did not send customer mail, move money, run payroll, reconcile real opening balances, or obtain two independent human approvals. No production deployment or customer cutover is implied.
