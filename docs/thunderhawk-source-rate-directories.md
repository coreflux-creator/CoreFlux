# Source rate repair and shared placement approval

Source repair now resolves saved JobDiva links in their original workspace, while rate rows remain in the current placement directory. It verifies the exact Start and candidate, rejects competing identities, preserves permanent display numbers and raw/prefixed provider pairs, and uses locked saved assignment evidence and field mappings. A missing snapshot requires an exact saved assignment mirror. Repair does not invent an assignment from display numbers, manufacture pay from bill rate, or approve a draft. Approved coverage and existing reviewed drafts remain intact. Every actual repair requires an audit in the same transaction.

Native draft creation and editing lock the current directory, placement and full rate range. Editing an imported draft records its editor and claims the placement's rates for Core. Ordinary JobDiva rate refresh, configured field mappings, and stored/CSV contract review recognize that ownership. Configured mappings also refuse to modify an approved snapshot, even without a native ownership flag. Native rate ownership remains after approval; changing rate values in Core is not temporary permission for the next source refresh to overwrite them.

Approval reads the current locked rate and calculates economics from its actual directory owner. It records the authenticated approver, snapshot and correction history on that owner row. Closing prior coverage and both approval/supersede audits occur in one transaction. Audit or economics failure rolls back the entire operation. Placement promotion uses the same service and propagates failure to the outer placement edit. A shared-workspace draft queue reads the shared owner and excludes unrelated companies. Source-repair API access requires both integration management and placement financial management; ordinary approval retains its financial-approval permission.
