# CoreAccounting MVP release gates

CoreAccounting is an independent product surface on the **existing CoreFlux/CoreOne accounting core**. Invoices, bills, bank transactions, approvals, subledger links and posted journals remain in their current source modules and shared ledger. This checklist is an acceptance ledger, not a claim of production readiness. Detailed evidence and decisions live in `COREACCOUNTING_COREONE_ALIGNMENT.md`. The fresh-package hosted check and subsequent private-runtime package update are recorded in `COREACCOUNTING_PACKAGE_QA3_ACCEPTANCE.md`.

For each behavioral release, create a representative synthetic item in isolated QA, verify its persisted outcome through the user workflow and source audit where applicable, and run the complete CI suite on the final commit. Record the test item, result and run link here; preview-only checks do not satisfy this gate. Never use production data for this requirement.
