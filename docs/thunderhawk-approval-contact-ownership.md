# Placement approval-contact ownership

The dedicated Approval setup screen previously wrote its contact fields directly, without setting Core ownership or requiring an audit in the same transaction. A later JobDiva refresh could replace that native choice. The installed change routes that screen through the native placement edit transaction.

The name and email are one ownership decision. Editing either field protects both; clearing an address explicitly remains protected. Returning the pair to JobDiva uses the existing reviewed handback. A partial handback is refused. Existing contacts are not retrospectively claimed as reviewed Core choices; the next authorized save establishes ownership. The dedicated route accepts only the two contact fields and the two approval settings, validates text against the native columns, and accepts explicit boolean values only. The general placement editor applies the same validation.

An unchanged retry is successful without another audit. Failed audit storage rolls back values and ownership. Focused setup never rebuilds economic parties, approves rates, or changes time. Existing placement access controls remain required.
